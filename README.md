# learning-java

A Java workspace for small to medium learning projects.

## Structure

Projects are grouped by topic so the repo stays readable as more projects are added.

- `projects/sqlvalidator` — SQL validator project
- `projects/datacoalesce` — data coalesce project
- `src/main/java` — shared application code if needed later
- `src/test/java` — shared tests if needed later

## Project layout

Each project can keep its own source and test folders:

```text
projects/<topic>/<project>/
  src/main/java/
  src/test/java/
```
